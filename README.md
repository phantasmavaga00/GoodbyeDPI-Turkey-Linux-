🚀 Kurulum

1. Depoyu indir

bash
git clone https://github.com/phantasmavaga00/GoodbyeDPI-Turkey-Linux-.git
cd GoodbyeDPI-Turkey-Linux-


2. Gerekli paketleri yükle — Ubuntu / Debian

bash
sudo apt update
sudo apt install -y \
  build-essential \
  libnetfilter-queue-dev \
  libmnl-dev \
  libnfnetlink-dev \
  nftables \
  dnsutils


3. Kurulum dosyalarını incele

bash
ls -la


Depodaki gerçek kurulum scriptini belirle, içeriğini kontrol et ve README'de belirtilen kurulum talimatlarını takip et. Script adı doğrulanmadan belirli bir komut varsayılmamalıdır.

🔍 Kontrol

DNS çözümlemesini test etmek için:

bash
dig discord.com +short


Quad9 bağlantısını kontrol etmek için on.quad9.net adresini ziyaret edebilirsin.
